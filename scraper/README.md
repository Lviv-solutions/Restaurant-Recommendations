# 🕷️ Restaurant Data Scraper & Generator

مجموعة شاملة من أدوات جمع وتوليد بيانات المطاعم للنظام. يحتوي على ثلاث طرق مختلفة لجلب البيانات مع إمكانيات متقدمة للتطبيع وإزالة التكرارات.

## 📁 محتويات المجلد

```
scraper/
├── README.md                 # هذا الملف - دليل شامل
├── package.json             # متطلبات Node.js
├── package-lock.json        # قفل الإصدارات
├── scraper.js              # كاشط Google Maps المتقدم
├── simple-scraper.js       # كاشط مبسط وموثوق
├── data-generator.js       # مولد البيانات الذكي
└── node_modules/           # المكتبات المثبتة
```

## 🎯 الأدوات المتاحة

### 1. 🤖 **مولد البيانات الذكي** (`data-generator.js`)
**الأداة الموصى بها** - سريع وموثوق 100%

```bash
node data-generator.js
```

**الميزات:**
- ✅ **43 مطعم حقيقي** من الرياض
- ✅ **سرعة فائقة** (أقل من ثانية)
- ✅ **موثوقية 100%** بدون أخطاء
- ✅ **بيانات غنية** مع أوصاف مخصصة
- ✅ **تنوع شامل** في المطابخ والأسعار

**البيانات المولدة:**
- مطاعم تراثية سعودية (نجد فيليج، الأصالة، البيت النجدي)
- مطاعم لبنانية (الشام، بيروت، كرم بيروت)
- مطاعم عالمية (تركية، هندية، صينية، إيطالية)
- مقاهي ووجبات سريعة (ستاربكس، البيك، ماكدونالدز)

### 2. 🕷️ **كاشط Google Maps المتقدم** (`scraper.js`)
كاشط شامل مع ميزات متقدمة (قد يواجه مشاكل تقنية)

```bash
node scraper.js
```

**الميزات:**
- 🔍 **8 استعلامات مختلفة** (عربي/إنجليزي)
- 📊 **تطبيع بيانات متقدم**
- 🔄 **إزالة تكرارات ذكية**
- 📈 **إحصائيات مفصلة**
- 🎯 **تصفية حسب النوع**

**التحديات:**
- ⚠️ قد يواجه مشاكل WebSocket
- ⚠️ يحتاج Chrome مثبت
- ⚠️ قد يتم حظره من Google

### 3. 🎯 **كاشط مبسط** (`simple-scraper.js`)
نسخة مبسطة أكثر استقراراً

```bash
node simple-scraper.js
```

**الميزات:**
- ✅ **أكثر استقراراً** من النسخة المتقدمة
- ✅ **معالجة أخطاء محسنة**
- ✅ **واجهة بسيطة**
- ⚠️ **ميزات أقل** من النسخة المتقدمة

## 🔍 استكشاف الأخطاء

### **مشاكل شائعة وحلولها:**

#### 1. **خطأ في تثبيت Puppeteer:**
```bash
# الحل
npm install puppeteer --unsafe-perm=true
# أو
PUPPETEER_SKIP_CHROMIUM_DOWNLOAD=true npm install puppeteer
```

#### 2. **خطأ WebSocket في الكشط:**
```bash
❌ Error: socket hang up
💡 الحل: استخدم مولد البيانات بدلاً من الكشط
node data-generator.js
```

#### 3. **عدم وجود Chrome:**
```bash
❌ Error: Could not find Chrome
💡 الحل: تثبيت Chrome أو استخدام مولد البيانات
```

#### 4. **فشل الاتصال بـ API:**
```bash
⚠️ لم يتم إرسال البيانات إلى API
💡 الحل: تأكد من تشغيل الخدمات
docker-compose up -d
```

### **نصائح لحل المشاكل:**
1. **استخدم مولد البيانات** كخيار أول
2. **تأكد من تشغيل الخدمات** قبل الكشط
3. **تحقق من اتصال الإنترنت** للكشط
4. **أغلق Chrome** قبل تشغيل الكاشط
